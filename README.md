# DJ ESTRE — editorial one-page website

Готовая первая версия сайта DJ ESTRE для Vercel на **Next.js 16 + React 19 + TypeScript**.

## Быстрый запуск

```bash
npm install
npm run dev
```
Открыть http://localhost:3000

Проверка production-сборки:
```bash
npm run build
npm start
```

## Публикация на Vercel

1. Создать репозиторий GitHub и загрузить содержимое папки `dj-estre-site` (файлы `package.json`, `app`, `components`, `lib`, `public` — в корень репозитория).
2. В Vercel нажать **Add New → Project** и импортировать репозиторий.
3. Framework Preset: **Next.js**. Build Command — `next build` (обычно определяется автоматически).
4. Нажать **Deploy**. Получить адрес вида `your-project.vercel.app`.
5. Добавить собственный домен в **Settings → Domains** при необходимости.

**Важно:** сайт для продвижения услуг — коммерческое использование. Проверьте актуальные правила и тарифы Vercel перед публикацией: https://vercel.com/pricing

## Что менять

- `lib/content.ts` — все тексты, ссылки, регалии, клиенты, музыка, фотогалерея.
- `app/globals.css` — цвета, типографика, анимации и адаптивный дизайн.
- `public/photos/` — заменить 6 дизайнерских SVG-заглушек настоящими фотографиями. После замены поменять пути в `lib/content.ts`, например `/photos/show-01.jpg`.
- `public/media/estre-demo-loop.wav` — оригинальная 24-секундная **демонстрационная** музыкальная петля. Заменить своим сетом в формате MP3, поменяв `audio` и `length` в `lib/content.ts`.
- `content.videoArchive` — ссылка на текущую папку с видео; можно заменить на YouTube/Vimeo или отдельные видео.
- `content.email` и `content.whatsapp` — сейчас пустые; соответствующие кнопки автоматически появятся после заполнения.

## Что уже работает

- Навигация с плавным скроллом и мобильным меню.
- Тёмный hero, editorial typography, responsive mobile/tablet/desktop.
- HTML5-аудиоплеер: play/pause, прогресс, перемотка, конец трека.
- Раздел видео с переходом в предоставленную Google Drive папку.
- Фотогалерея с категориями, полноэкранным просмотром, кнопками и клавишами Esc/←/→.
- Достижения, заказчики, Telegram CTA и SEO-метаданные.

## Известные ограничения первой версии

- В папке `public/photos` нет реальных фотографий DJ ESTRE — только уникальные дизайнерские заглушки.
- В аудиоплеере не авторский сет DJ ESTRE, а специально сгенерированное для макета демо.
- Видео пока открывается по внешней ссылке на предоставленный архив, не проигрывается в модальном окне.
- Форма с сохранением заявок пока не добавлена: доступно бронирование через Telegram; WhatsApp/email появятся после заполнения контактов.
- Логотипы клиентов заменены их текстовыми названиями.
- Удалённый Google Fonts импорт требует интернет-соединения; без сети сайт использует системные fallback-шрифты.

Не размещайте клиентские, фото- и видеоматериалы без необходимых прав и согласований.
