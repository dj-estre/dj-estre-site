# DJ ESTRE — Next.js + Sanity CMS

Одностраничный сайт-портфолио с встроенной админ-панелью `/studio`.

## 1. Создать проект Sanity

Перейди на https://www.sanity.io/manage, создай проект **DJ ESTRE** и dataset **production** (публичный). Скопируй Project ID.

## 2. Подключить Vercel

В Vercel → Project → Settings → Environment Variables добавить:

- `NEXT_PUBLIC_SANITY_PROJECT_ID` — Project ID
- `NEXT_PUBLIC_SANITY_DATASET` — `production`

Не вставляй сюда секретные токены. Укажи переменные для Production (и Preview при необходимости). Выполни Redeploy.

## 3. Обновить GitHub

Замени файлы текущего репозитория содержимым этого архива. **Не загружай ZIP как один файл**. Vercel автоматически начнёт новую сборку после коммита.

## 4. Авторизация и CORS

Sanity → Manage → API → CORS origins: добавь `https://ТВОЙ-ДОМЕН.vercel.app` и/или собственный домен. Для встроенной Studio включи **Allow credentials**. Авторизуйся на `https://ТВОЙ-ДОМЕН/studio` под своим Sanity аккаунтом с правами редактирования проекта.

## 5. Управление содержимым

В Studio есть разделы: Настройки сайта, Музыка, Видео, Фото, Достижения, Клиенты. Создавай и **Publish** записи.

Сайт получает опубликованные материалы при каждом открытии страницы (динамический серверный рендеринг). Пока коллекция пустая, отображаются прежние демонстрационные данные. Новые записи в коллекциях музыки, фото, достижений или клиентов заменяют демонстрационные записи соответствующей коллекции.

### Особенности плеера

Встроенный плеер играет первый опубликованный аудиофайл. Остальные музыкальные записи с внешними URL открываются по ссылке. Для большого количества аудио удобнее использовать специальные аудиохостинги — лимиты хранения и трафика Sanity зависят от тарифа.

## Локально

```bash
npm install
cp .env.example .env.local
# Вставить реальный Project ID в .env.local
npm run dev
```

Открой http://localhost:3000 и http://localhost:3000/studio.

## Замечания

- Доступ к содержимому Studio требует авторизации Sanity. Публичный сайт читает только опубликованные документы из публичного dataset.
- Настройки сайта необязательны: используются дефолтные тексты до публикации.
- Поля фотографий сохраняют оптимизированные URL Sanity CDN; проигрывание аудио зависит от формата и браузера.
- Никакие реальные личные контактные данные не придуманы и не добавлены.
